Design note

The menu opens from the Export button. Scope comes first, because it changes every item below: Current view follows the tab and the search, All tests ignores both. The menu says how many tests each choice holds, and the choice is remembered until you leave the page. Items are verb plus object. Copy top Flaky tests keeps its v0 place and words. Arrow keys move between items, Enter runs one, Esc closes and returns focus to Export.

4. What is in the files

What each file holds
flakelens-tests.csvOne row per test, in the table order. Columns: rank, test, file, project, status, score, mixed commits, flip rate, attempts, wasted minutes, evidence, first seen, last failed. Opens in Excel and Sheets. Cells that start with = + - or @ are made safe.
flakelens-tests.json{ app, version, exportedAt, scope, tests }. Every field the app has, for scripts.
flakelens-report.mdThe report on this page. Plain Markdown, special characters escaped.
Sample dataFiles made from sample data say "sample data" inside them.
Design note

File names are fixed so they are easy to find and to attach. Spreadsheet-safety is a rule of the file, not a setting: a cell that starts with = + - or @ is prefixed so a spreadsheet cannot run it.

Design note

Each toast says what happened, with the file name and the number of tests. Toasts are status role; a failed copy is an alert and offers the file as another way. Large exports finish in under a second, so there is no progress bar.
