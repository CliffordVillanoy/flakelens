How do I get a report file?
In CI, run your tests with the JSON reporter and save the file as an artifact:
npx playwright test --reporter=json > results.json
Then download that file from your last 5 to 10 CI runs and drop them all here at once.
Only one run? Turn on retries, or add --repeat-each=5 once, so a single run already shows flakiness.
Using JUnit XML? Drop the XML files the same way. Maven writes them to target/surefire-reports.
