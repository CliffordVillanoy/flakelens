System banners and toasts

v1 (DEV-17, DEV-20, DEV-42). How the app tells you about storage, updates, offline use and installing, without blocking your work.

1. Storage banners (in page, under the header)

Storage off: only when there is data to lose

This browser won't keep your data after you close the tab. Results are still shown for now.

Storage failed: role alert, never a blank page

Your saved data couldn't be read. Reload the page to try again. If it keeps happening, clear all data and import your files again.

Saved imports skipped: valid rows still load

2 saved imports couldn't be read and were skipped. Clear all data to remove them.

Design note

One flat style: a 1px edge, an icon, normal text. Amber edge and triangle for warnings. Red edge and soft red fill for the one error. Banners sit in the page flow, never over content, and push the page down. Only one storage banner shows at a time: failed beats skipped beats off. Dismiss hides a warning until the next page load. The error has no Dismiss, only Reload page. The skipped banner gets a Clear all data action that opens the usual confirmation.

2. Update and offline toasts (DEV-42)

Update ready: stays until you act. No timer
A new version of FlakeLens is ready. Reload to use it.
Update ready while storage is off: says what Reload costs
A new version is ready. Reloading clears your results because this browser isn't saving them.
Offline ready: shows once, closes itself after 8 seconds
FlakeLens now works offline.
Design note

The new version waits in the background. The page never swaps files by itself, so nothing changes under you mid-task. The update toast is quiet (status role, no focus steal) and stays until Reload or Dismiss. A dismissed update reminds again on the next page load only. Offline ready appears once per install, with a thin timer bar.

3. Install, inside Settings under About (no pop-up)

Browser can install: a button
Install FlakeLens
Already installed: status only
FlakeLens is installed
Installed
Safari: how-to text, no button
On iPhone or iPad: Share, then Add to Home Screen
Design note

There is no install pop-up and no nag banner. The row lives in Settings under About and shows only when the browser allows it; it hides entirely when it cannot. The button opens the browser's own install dialog. After installing, it turns into a status pill.

4. Where they live, and how they stack

Label saved. Rankings updated.
Design note

Banners: top of the page body, full content width (max 1232px), one at a time. Toasts: bottom left on desktop, full width above the bottom edge on phones; newest at the bottom; at most 2 on screen, and the older one closes first, except an update toast, which is never pushed out. Toasts never take focus; the action is reachable by Tab after the page content. Esc closes the focused toast. Toasts fade in over 150 ms and honour reduced motion.
