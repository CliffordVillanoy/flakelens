Design note

The label is a persistent field above the box, never a placeholder only. Empty means: use the commit from the report, or, if there is none, treat the file as its own commit. The tag at the right of the label says where the value comes from.

Design note

Enter saves, Esc cancels, Save label and Cancel appear only while editing. Saving recomputes Tests and the Evidence text at once and announces "Label saved. Rankings updated." (role status). Removing the label (the x) announces "Label removed. Rankings updated."
