# FlakeLens v0 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (one DEV ticket at a time, as sent by the planning chat). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v0 browser app on top of the v0 engine: open the page, press "Try sample data" or drop Playwright JSON files, and reach a ranked, explained list of flaky tests in under two minutes, with nothing leaving the browser.

**Architecture:** React + Vite single-page app with hash routes. Files are parsed in a Web Worker (Comlink) with the existing `parsePlaywrightReport`. The user's dataset is stored in IndexedDB (Dexie); sample data is held in memory only. A Zustand store holds the dataset, derived scores and UI state. Screens follow the v0 wireframes and `DESIGN.md`; all user-facing text comes from one copy module built from `docs/ux/04-ux-copy.md`. The engine stays pure (`src/engine/**`); UI code lives in `src/ui/**`.

**Tech Stack:** React 19, TypeScript 6 (strict), Vite 8, Tailwind CSS (v4, `@tailwindcss/vite`), shadcn/ui (Radix primitives), lucide-react, Zustand, Dexie, Comlink, TanStack Table + TanStack Virtual, Vitest + Testing Library + jsdom, Playwright + `@axe-core/playwright`.

**Spec:** `docs/SPEC.md` (sections 6, 8, 9.1, 11, 13, 13.1, 13.2, 13.3, 15, 16, 19.1). Design: `DESIGN.md` (normative tokens and components), `PRODUCT.md`. UX: `docs/ux/02-information-architecture.md` (routes, flows, states), `docs/ux/04-ux-copy.md` (binding copy and glossary), `docs/ux/00-handoff-v0.md`, wireframes in `docs/ux/wireframes/` (preview: launch config `wireframe-preview`).

**Tickets:** this plan is delivered as DEV-11 to DEV-18 in `docs/dev/`. Each ticket names its tasks here.

## Global Constraints

- **No network by default.** No CDN, no analytics, no external fonts. The only requests the app makes are to its own origin (app files and `sample/*`). Fonts are self-hosted.
- **Engine boundary:** `src/engine/**` keeps its ESLint rules (no UI, DOM or `fetch`). New engine helpers are pure and tested there.
- **No raw HTML:** imported text renders as text only. ESLint bans `dangerouslySetInnerHTML` (spec 19.1). CSV and Markdown exports escape their content.
- **Copy:** every visible string comes from `src/ui/copy.ts`, keyed exactly as in `docs/ux/04-ux-copy.md`, including its renames (sections 6–8: Unproven, "not imported", the Evidence column). No literal UI strings in components.
- **Status display:** pills show the word only (22px high, min width 76px). Run squares: passed solid green, failed hollow red (2px outline), passed on retry solid amber, skipped solid gray. Display names: Flaky, Unproven, Failing, Stable, Not enough data for engine labels `flaky`, `suspect`, `failing`, `stable`, `insufficient`.
- **Order:** groups Flaky, Unproven, Failing, Stable, Not enough data; inside groups use `rankTests` order. Stable and Not enough data start collapsed.
- **Tokens:** CSS variables from the `DESIGN.md` variable map, dark on `:root`, light under `[data-theme="light"]`. No shadows, no gradients. 2px accent focus ring with 2px offset. Comfortable density (40px rows, ranked rows 56px) is the default; Compact is 32px.
- **Accessibility:** WCAG 2.2 AA. Full keyboard use, visible focus, `prefers-reduced-motion` respected, targets at least 24×24px, single-key shortcuts never fire in text fields and can be switched off.
- **Storage:** user data lives in IndexedDB only. `localStorage` holds only preferences (theme, density, columns, shortcuts on/off), every access wrapped in try/catch. Sample data is never stored.
- **Hosting:** static GitHub Pages at `https://cliffordvillanoy.github.io/flakelens/`. Vite `base: './'` so the build works under any path; hash routing (`#/`, `#/tests`, `#/tests/:testId`, `#/data`).
- **Dependencies:** each new package is $0 with a permissive licence; record name, version and licence in the ticket report. No package for something a few lines can do.
- **Commits:** plain messages, no Claude attribution. All v0 UI tickets go on one branch, `feat/v0-ui`, cut from `main`. It is merged to `main` only after the final review and the user's approval. No push until then.

## Review Focus

1. **A dataset of 5,000 tests and 50 runs** (large suites): the table must stay responsive (virtual rows) and import must not freeze the page. Test in DEV-18 with a generated fixture.
2. **Private-mode or blocked IndexedDB:** the app must still work for the session and show `storage.off`, never a blank page. Test in DEV-12.
3. **Dropping the same file twice in one drop:** one run kept, one `import.dupeRun` notice, no import-ID collision in storage. Test in DEV-12.
4. **Test names with HTML, very long names, RTL and emoji:** rendered as plain text, truncated with a full-name tooltip, layout intact. Test in DEV-14.
5. **Reload on `#/tests/<id>` after Clear all data:** shows `missing.test.*` with "Back to tests", or Start when no data is left. Test in DEV-16.

### Task 1 (DEV-11): UI foundation, tokens, fonts, copy, router

**Files:** `index.html`, `src/main.tsx`, `src/ui/styles.css`, `src/ui/App.tsx`, `src/ui/copy.ts`, `src/ui/lib/router.ts`, `src/ui/lib/prefs.ts`, `src/ui/components/Header.tsx`, `public/fonts/*`, `public/brand/*`, `eslint.config.js`, `vite.config.ts`, `components.json`
**Tests:** `src/ui/copy.test.ts`, `src/ui/lib/router.test.ts`, `src/ui/lib/prefs.test.ts`, `src/ui/components/Header.test.tsx`

**Interfaces (produced):**
- `t(key: CopyKey, params?: Record<string, string | number>): string` — `CopyKey` is a string-literal union of catalog keys. Supports `{name}` and `{count, plural, one {...} other {...}}` with `#`, via `Intl.PluralRules('en')`.
- `useRoute(): { name: 'start' | 'tests' | 'test' | 'data'; testId?: string; query: URLSearchParams }` and `navigate(hash: string): void`.
- `getPref<T>(key: string, fallback: T): T`, `setPref(key: string, value: unknown): void` — never throw.

- [ ] **Step 1: Install** `tailwindcss @tailwindcss/vite lucide-react` and run the shadcn/ui init (`components.json`, `src/ui/components/ui`, alias `@/` → `src/`). Dev: `jsdom @testing-library/react @testing-library/user-event @testing-library/jest-dom`.
- [ ] **Step 2: Vitest projects:** keep `environment: 'node'` for engine, lab and scripts; use `jsdom` for `src/ui/**/*.test.tsx?`.
- [ ] **Step 3: Failing tests first:**
  - copy: `t('import.reading', { count: 1 })` → `Reading 1 file…`; `{ count: 3 }` → `Reading 3 files…`; a missing param throws in tests (so typos fail loudly); every key in the catalog is a non-empty string.
  - router: `#/tests?status=flaky&q=login` → `{ name: 'tests', query.get('status') === 'flaky' }`; `#/tests/abc` → `{ name: 'test', testId: 'abc' }`; unknown hash → `start`.
  - prefs: when `localStorage` throws, `getPref('x', 1)` returns `1` and `setPref` does not throw.
  - Header: renders the logo with `aria-label="FlakeLens"`, the privacy line `header.privacy`, "Add your files", theme and help icon buttons with accessible names; the theme button toggles `data-theme` on `<html>` and saves the pref.
- [ ] **Step 4: Implement.** Tokens: copy every value from the `DESIGN.md` CSS variable map and the light table, map into Tailwind via `@theme inline`. Base control rule (`color-scheme`, `color: inherit` on controls, fg-muted placeholders). Fonts: Mona Sans (400, 500, 600, 700) and JetBrains Mono (400) as woff2 from their official OFL releases, `font-display: swap`, licence files alongside. Logo: copy the two SVGs from `docs/ux/brand/` unchanged. Theme bootstrap: an inline-free approach (set `data-theme` in `main.tsx` before render from the saved pref; dark by default).
- [ ] **Step 5: CSP** in `index.html`: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; worker-src 'self'; object-src 'none'; base-uri 'self'; form-action 'none'`. (`'unsafe-inline'` styles are needed for virtual-row positioning; scripts stay strict.)
- [ ] **Step 6: ESLint:** add `react/no-danger`-equivalent rule (`no-restricted-syntax` on JSXAttribute `dangerouslySetInnerHTML`) for `src/**`.
- [ ] **Step 7: Verify:** `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`; `npm run dev` shows the header in dark and light with the self-hosted fonts and no network requests outside the origin (browser devtools).

### Task 2 (DEV-12): Data layer — worker import, storage, sample, store

**Files:** `src/engine/view.ts`, `src/engine/types.ts` (new notice code), `src/engine/import/playwright.ts`, `src/ui/data/{db,worker,importer,sample,store,selectors}.ts`
**Tests:** `src/engine/view.test.ts`, `src/engine/import/playwright.date.test.ts`, `src/ui/data/*.test.ts` (Dexie via `fake-indexeddb`, dev dependency)

**Interfaces (produced):**
- Engine: `orderRuns(runs: Run[]): Run[]` (move the comparator out of `score.ts`, reuse it there); `runHistory(ds: Dataset, testId: string): RunCell[]` where `RunCell = { run: Run; attempts: AttemptStatus[]; outcome: 'pass' | 'fail' | 'retryPass' | 'skip'; mixedCommit: boolean }`, oldest first; `lastRuns(ds, testId, n = 12): RunCell[]`.
- Engine: new `NoticeCode` `'import.partial.badDate'`, severity `info`, emitted when `stats.startTime` is present but unreadable (result stays `success`). Add the copy key `import.partial.badDate` with: `{file}: the run start time couldn't be read, so this run keeps its import order.` (tell the UI/UX chat in the report).
- `saveImport(res: ImportResult): Promise<void>`; `loadDataset(): Promise<Dataset>`; `clearAll(): Promise<void>`; `storageAvailable(): Promise<boolean>`. `saveImport` makes `importId` unique if it already exists (`hashString(id + '#' + n)`), covering the DEV-02 note.
- Worker: `parseFiles(files: { name: string; text: string; commitLabel?: string }[], importedAt: string, onProgress: (i: number) => void): Promise<ImportResult[]>`.
- `runImport(files: File[], opts: { commitLabels?: Record<string, string>; signal: AbortSignal }): Promise<ImportSummary>` — reads files, parses in the worker (terminate on abort or after 30 s per file), applies `addImport` in order, persists unless in sample mode. `ImportSummary = { records: ImportRecord[]; newFlaky: number }`.
- `loadSample(): Promise<Dataset>` — fetches `sample/manifest.json` and its files relative to the page, parses with the manifest commits. Counts come from the data (13 runs today).
- Store (Zustand): `{ mode: 'empty' | 'user' | 'sample'; dataset: Dataset; ranked: TestScore[]; importing: ImportProgress | null; storage: 'ok' | 'off' | 'failed' }` with actions `restore()`, `importFiles()`, `startSample()`, `exitSample()`, `clearAll()`. `ranked` = `rankTests(scoreTests(dataset), dataset.tests)`, recomputed on change.

- [ ] **Steps (TDD for each interface):** engine view tests (order with mixed timed and untimed runs matches `scoreTests`; `retryPass` when a run has a fail then a pass; `mixedCommit` when a commit has both); bad-date notice; `saveImport`/`loadDataset` round-trip; collision on same `importId`; `storageAvailable()` false → store `storage: 'off'` and import still works in memory; same file twice in one call → one run plus `import.dupeRun`; sample mode never calls `saveImport`; abort terminates the worker and leaves the dataset unchanged; `newFlaky` counts tests that became `flaky` since the previous dataset.
- [ ] **Verify and commit.**
