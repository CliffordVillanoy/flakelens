# Flake lab: cause classifier report

Generated by `npm run eval:causes` from `fixtures/lab/` and `flake-lab/labels.json`. Do not edit by hand.

## Method

- Test set: the 15 lab tests that fail and have an injected cause in `flake-lab/labels.json` (a test that runs in two Playwright projects counts once per project).
- Each failure is classified by `classifyFailure` from its own raw message and stack (not from the group template); a failure in an environment event group is classified with `environmentEvent` on. The test gets the cause most of its failures voted for. A tie goes to a real cause, never to unknown.
- `unknown` means no rule fired. It is counted as wrong in the accuracy and shown in its own column.
- The rules in `src/engine/cause/rules.ts` were written from Playwright and Node error text before the lab results were looked at, and were not changed to fit the lab. The numbers below are what they are.

## Limits

This is a synthetic lab with messages we injected ourselves, one test or a few per cause (15 tests are scored), 12 runs over 6 commits. The sample is small, so one test moves a category by a large share, and an accuracy figure here is not a real-world accuracy. The same people wrote the rules and the lab messages, so the lab text is close to the text the rules look for: **the numbers are probably optimistic for real suites** (overfitting risk). The causes that need context rather than text (order dependency, shared state, time and randomness, timing without a timeout message) have few or no rules that can fire on a bare assertion failure, so they show up as unknown here, and that is expected to stay true on real data. The check on public real-world failure logs (spec section 11.1, item 5) is a later step and needs the JUnit importer.
